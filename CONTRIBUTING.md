# Contributing

Thank you for considering a contribution to Inventory-App!

## Reporting Issues

- Search existing issues before opening a new one.
- Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) templates.

## Pull Requests

- Follow the [pull request template](.github/pull_request_template.md).
- Run `make ci` (formats with Black, lints with Ruff, runs pytest) and ensure all checks pass.
- Maintain code style and add tests and documentation where appropriate.

We appreciate your help in improving the project.
